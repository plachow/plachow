# plachow

Testovací repozitář pro spolupráci přes AI agenty.

## Jak to funguje

- Větev `main` je chráněná. Nikdo do ní nepushuje přímo.
- Změnu navrhneš slovně svému agentovi (Claude Code, Codex). Ten vytvoří větev a otevře Pull Request.
- Správce repa PR zkontroluje a sloučí do `main`.

## Obsah

- `index.html` je jediná stránka webu.
